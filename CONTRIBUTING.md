# Contributing

Use Node.js 24 and pnpm 11. Run `pnpm install --frozen-lockfile --ignore-scripts`, `pnpm run build`, `pnpm run lint`, and `pnpm test`. Never add API tokens or private prompts to commits. Submit changes through a PR with contract, test and example updates. Keep this package limited to the Ace Data Cloud Chat API and free of bundled runtime dependencies.
